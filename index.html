Document: nav, main, section, article, aside, header, footer, figure, time, mark — what each does and when to use it.

HTML Tag What It Does When To Use
<nav> Defines navigation links. Use for menus, navbar, or page links.
<main> Represents the main content of the webpage. Use for the central content section.
<section> Groups related content together. Use for chapters, topics, or page sections.
<article> Defines independent content. Use for blogs, news articles, or posts.
<aside> Contains side information. Use for sidebars or related links.
<header> Represents introductory content. Use for page titles or top sections.
<footer> Defines footer information. Use for copyright or contact info.
<figure> Groups media content with captions. Use for images, diagrams, or illustrations.
<time> Represents date or time. Use for schedules, events, or timestamps.
<mark> Highlights important text. Use to emphasize keywords or notes.
